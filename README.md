# fire-defence3
Defence from the fireball attack.

需要修正項目：1. 解鎖魔法陣輸入改用魔杖
             2. 遊戲畫面說明文檔著龍頭，需要隱藏
             3. 修改移動中的火球碰到巫師帽一樣會扣一頂帽子
             4. 每吐完一次火焰，接著吐火球飛行速度增加0.5秒
             5. 畫面上方巫師火元素特訓的提示框 應安排在倒數計時之前。 提示框下方可以出現一個小的魔法陣，代表讀完的遊戲開始鍵。 魔法陣周圍可以散發出藍色向外的漸層光。 當魔法棒點擊此魔法陣，即開始倒數計時。
             6. "點擊螢幕，喚醒魔杖"與魔法陣太近。
             7. 進入繪製魔法陣，提示詞會檔著魔法環。
             8. 生命欄位出現在螢幕正中，會影響遊戲體驗，請將生命欄位移至螢幕最下方。 
             9. 只保留成功攔截的統計次數，刪除防禦失敗次數。 此兩種顯示欄位適當大小排列在螢幕最下方。
             10. 會治魔法陣畫面背景是否可有一個黑色半透明的屏幕 這樣可以讓魔法環還有繪製魔法陣更清楚明確
